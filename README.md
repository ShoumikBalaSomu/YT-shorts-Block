# 🚫 Ultimate YouTube Shorts Blocker

A comprehensive, advanced filter list designed to completely block YouTube Shorts across all platforms. This list prevents bypasses, blocks background API calls, prunes search results, and hides all Shorts-related UI elements.

## ✨ Features
- **Blocks Direct URLs**: Prevents access to `youtube.com/shorts/*`.
- **Hides UI Elements**: Removes Shorts tabs, shelves, badges, and the homepage button on both Desktop and Mobile.
- **Search Result Pruning**: Strips Shorts from search results and homepage shelves at the JSON level before they render.
- **Anti-Bypass**: Blocks alternative URL parameters and embed tricks.
- **Cross-Platform**: Compatible with uBlock Origin, AdGuard, and Brave Shields.

## 📦 Installation
1. Open your adblocker dashboard (uBlock Origin / Brave).
2. Go to **Filter lists** > **Custom** > **Import**.
3. Paste the following URL:
   `https://raw.githubusercontent.com/ShoumikBalaSomu/YT-shorts-Block/main/blocklist.txt`
4. Apply changes and refresh YouTube.
