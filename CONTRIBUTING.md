# Contributing to YT-Shorts-Block

## Report a Bypass
1. Go to Issues -> New Issue -> Bug Report
2. Include: URL, browser + version, screenshot
3. We fix within 48 hours

## Submit a Fix
1. Fork the repo
2. Create branch: git checkout -b fix/shorts-bypass
3. Make changes, test on Chrome + Firefox + Brave
4. Submit Pull Request

## Testing Checklist
- Search "python tutorial" -- no shorts in results
- Visit youtube.com/shorts/VIDEO_ID -- redirects
- Homepage -- no shorts shelf
- Channel page -- no Shorts tab
- Sidebar -- no Shorts button
- Mobile web -- all shorts hidden
