Why use this?

Standard adblockers only hide the Shorts button. This list blocks the underlying API calls, prevents redirects, and hides all Shorts elements across Desktop and Mobile, ensuring you never accidentally click a Short again.

How to Install

uBlock Origin

  1. Open uBlock Origin Dashboard (⚙️)
  2. Go to the Filter lists tab
  3. Scroll down to Custom and click Import
  4. Paste: https://raw.githubusercontent.com/ShoumikBalaSomu/YT-shorts-Block/main/blocklist.txt
  5. Click Apply changes

Brave Browser

  1. Go to brave://settings/shields/filters
  2. Scroll to Custom filters and click Add custom filter list
  3. Name it and paste the URL above
