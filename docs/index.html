Why YT-Shorts-Block?

YouTube Shorts are engineered to be addictive. We block them at every possible layer so there is no bypass.

🌐

URL Blocking

All /shorts/ URLs are intercepted and redirected. Direct links, shared links, embedded links - all blocked before the page loads.

🎨

DOM Element Removal

Every Shorts shelf, button, tab, and card is removed from the page. MutationObserver catches dynamically loaded content.

🛡

CSS Shield

Instant CSS rules hide Shorts elements at document_start - before you even see them. Zero flash of content.

🔌

API Interception

Shorts API calls to youtubei.googleapis.com are blocked. YouTube cannot even fetch Shorts data.

📱

Mobile Support

Works on mobile YouTube (m.youtube.com), Android DNS blocking, and iOS content blockers.

🔒

Privacy First

Zero data collection. No tracking. No analytics. No external requests. Fully auditable open-source code.

Install in 30 Seconds

The fastest way: add our filter list to uBlock Origin or Brave Shields.

1

Open uBlock Origin Dashboard

Click the uBlock icon → Dashboard → Filter lists tab. Scroll to the bottom.

2

Import Our Filter List

Click "Import" and paste this URL:

https://raw.githubusercontent.com/ShoumikBalaSomu/YT-shorts-Block/main/filter-lists/yt-shorts-ublock.txt
3

Apply & Enjoy

Click "Apply changes". Refresh YouTube. Shorts are gone. Forever.
